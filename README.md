# ⚡ F5 Pro Master v2.6
**The Ultimate Fantasy 5 Strategy & Vault Suite**

This is a specialized, mobile-optimized application designed to manage Arizona Fantasy 5 play strategies. It combines historical pattern analysis with a "Barbell" probability engine to optimize number selection.

## 🚀 Core Features
* **AI Barbell Generator**: Splits picks between **Trend** (Hot numbers from history) and **Trap** (Cold numbers due for a hit).
* **10-Day Multi-Draw Vault**: Track tickets across up to 10 consecutive draws with automatic "Days Left" countdowns.
* **200-Draw Intelligence**: A dedicated History tab that stores and analyzes the last 200 actual winning draws to feed the generator.
* **Auto-Sync History**: One-button "Finalize" to check winners and move them into the history log simultaneously.

## 📊 Strategy: Hot/Cold Weighting
The system uses the **Barbell Method**:
1.  **Trend Picks**: Target numbers with high frequency in the 200-draw log.
2.  **Trap Picks**: Target numbers with high "gap" counts (numbers that haven't hit recently).

## 🛠️ Data Integrity & Backups
This repository includes a standalone `backup.html` tool. It allows you to:
* Audit your lifetime **ROI** (Return on Investment).
* Download your 200-draw history as a `.txt` file for safe keeping.
* View data without modifying the core vault storage.
